## Sobre a atividade

Esse repositório contém a atividade de leitura do sensor de temperatura da matéria de IoT.

## Tinkercad

[Sensor de Temperatura](https://www.tinkercad.com/things/fze1tRBrO38-sensor-temperatura/)

## Enunciado

**Lendo o sensor de temperatura**

Montar um circuito utilizando um sensor de temperatura e três LEDs para indicar diferentes faixas de temperatura.

## Materiais necessários

| Qtd | Componente                 |
| --: | -------------------------- |
|   1 | Arduino Uno                |
|   1 | Protoboard                 |
|   1 | Sensor de temperatura LM35 |
|   1 | LED vermelho               |
|   1 | LED amarelo                |
|   1 | LED verde                  |
|   3 | Resistores de 220 Ω        |
|   — | Jumpers macho-macho        |
